## 🏦 What is the Botswana Tech Fund?

The **Botswana Tech Fund (BTF)** is a multi-stage venture capital initiative targeting technology startups across **Southern Africa**. It operates two investment tracks:

| Track | Stage | Capital Range | Best Fit For |
|---|---|---|---|
| **Accelerator Programme** | Pre-Seed | **£25,000 – £100,000** | ✅ Komunity right now |
| **Growth Strategy** | Seed → Series C | £500,000 – £2,000,000 | Future round |

The fund focuses on companies building the **software application layer on Africa's digital infrastructure** — exactly what Komunity does for cooperative finance.

## 💬 Your Core Pitch to BTF — 4 Key Angles

### 1. 🏗️ Infrastructure Play (BTF's Language)
> *"Komunity is building the cooperative finance application layer on top of Africa's mobile money and digital wallet infrastructure — the missing software layer that converts informal cash pools into transparent, auditable, digital cooperatives."*

BTF explicitly invests in **"software application layers"** on Africa's infrastructure. Komunity sits perfectly here: you're not building the payment rails — you're building the governance, trust, and automation software that sits on top of them.

### 2. 📊 Market Size
- **South Africa**: 11.5M people, 820,000 Stokvels, **$3.5B+ annually**
- **East Africa**: Chamas, Harambees — hundreds of millions of participants
- **West Africa**: Ajo/Susu savings circles
- **Total TAM**: $1 trillion+ in informal savings globally, almost entirely undigitized

### 3. 🔧 Technical Proof (Not a Mockup)
Komunity is a **fully-built, running platform** — not a pitch deck startup:
- ✅ Django REST API with 14 registered API endpoints
- ✅ React Native mobile app with 23 screens
- ✅ Double-entry ledger engine (fraud-proof)
- ✅ Biometric wallet security (FaceID/TouchID)
- ✅ Push notifications, deep linking, camera, haptics
- ✅ Working SQLite DB (626KB of real data)
- ✅ Local server running at `192.168.88.243:8000`

This is a **functional MVP** — a rare thing at pre-seed.

### 4. 💼 Revenue Model
- **1.5% withdrawal fee** — aligned with growth (more transactions = more revenue)
- **SaaS subscription** for cooperative unions/stokvel associations
- **Float monetization** on pooled reserves
